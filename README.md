# HTML Basics - Bootstrap Website Project

A simple multi-page website built with HTML5, CSS3, and Bootstrap 4 to demonstrate basic web development concepts and responsive design principles.

## 🌟 Project Overview

This project showcases a basic business website structure with multiple pages including Home, Products, Services, About, and Contact pages. It serves as an educational example of modern web development using popular frameworks and best practices.

## 📁 Project Structure

```
HTML_Basics/
├── README.md              # Project documentation
├── index.html            # Home page (main landing page)
├── about.html            # About us page
├── products.html         # Products/catalog page
├── service.html          # Services page
├── contacts.html         # Contact information page
├── mystyle.css           # Custom CSS styles
├── images/               # Image assets
│   ├── fitz_roy_mountain-1920x1080.jpg
│   ├── netflix-logo.png
│   └── woman.png
├── sounds/               # Audio files
│   └── music1.mp3
├── video/                # Video files
│   └── myvideo.mp4
└── LICENSE               # Project license
```

## ✨ Features

- **Responsive Design**: Built with Bootstrap 4 for mobile-first responsive layout
- **Multi-page Navigation**: Clean navigation menu across all pages
- **Modern CSS**: Custom styling with CSS3 features
- **Media Support**: Prepared structure for images, audio, and video content
- **Semantic HTML**: Proper HTML5 structure and accessibility considerations
- **Cross-browser Compatibility**: Works across modern web browsers

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and modern web standards
- **CSS3**: Custom styling and responsive design
- **Bootstrap 4.5.3**: Frontend framework for responsive design
- **Bootstrap Icons**: Icon library for enhanced UI
- **jQuery 3.5.1**: JavaScript library for enhanced interactivity

## 🚀 How to Use

1. **Clone or Download**: Download the project files to your local machine
2. **Open in Browser**: Navigate to the project folder and open `index.html` in your web browser
3. **Navigate**: Use the navigation menu to explore different pages
4. **Customize**: Modify the HTML, CSS, and content to suit your needs

## 📖 Page Descriptions

- **Home (`index.html`)**: Main landing page of the website
- **Products (`products.html`)**: Showcase products or services offered
- **Services (`service.html`)**: Detail the services provided
- **About (`about.html`)**: Information about the company or project
- **Contact (`contacts.html`)**: Contact information and forms

## 🎨 Styling

The project uses a combination of Bootstrap classes and custom CSS:

  - Border styling and border-radius
  - Background colors and text alignment
  - Spacing and layout adjustments
